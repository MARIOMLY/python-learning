## 每周日怎么更新（三条命令）

在 VS Code 里打开本目录，按 `` Ctrl+` `` 打开终端，依次执行：

```bash
git add .                          # 把本周的改动加进来
git commit -m "第2周：条件判断"      # 打包成一次提交（说明改成当周内容）
git push                           # 推到 GitHub
```

第一次推送时输入的 token 已经保存在本机，之后不用再输。
如果某天推送时又要求输入密码，说明 token 过期了 —— 去 GitHub 重新生成一个即可。

> **在线学习页会自动更新**：`index.html` 推上去之后，等 1 分钟左右，
> https://mariomly.github.io/python-learning/ 就会变成最新版。

> 网页打卡记录的代码不会自动出现在这里。如果代码只在网页里写过，用页面上的
> 「💾 我的代码 → 打包全部 28 天」下载 zip，解压后覆盖到对应 week 目录再提交。
